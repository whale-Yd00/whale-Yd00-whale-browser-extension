# whale-Yd00-whale-browser-extension
神秘暴力读浏览器插件
浏览器扩展：读取当前网页文字
这个扩展用于解决 Jina Reader 无法读取登录态页面、JS 渲染页面或被反爬拒绝的情况。它只在用户点击扩展按钮时读取当前标签页 DOM 中的文字，不读取 Cookie、token 或账号信息。

安装
打开 Chrome / Edge 的扩展管理页。
Chrome: chrome://extensions
Edge: edge://extensions
开启“开发者模式”。
选择“加载已解压的扩展程序”。
选择项目里的 browser-extension 文件夹。
使用
在浏览器中打开知乎、小红书等目标页面。
需要评论区或折叠内容时，先在页面里滚动或点开，让文字实际加载出来。
点击扩展按钮，确认弹窗里读到了正文。
可直接“复制”，再粘贴到 Whale 聊天框。
也可以选择目标应用并填写网页地址：
Whale 网页版：例如 http://localhost:8080/index.html，点击“发送到 Whale”。
SullyOS 网页版：例如 http://localhost:5173/，点击“发送到 SullyOS”。
Whale 打开后选择角色，聊天框里会出现网页标题/链接；发送后，正文会作为网页上下文交给 AI。
首次发送到 SullyOS 时，浏览器会询问是否允许扩展访问 SullyOS 页面；同意后扩展才能把卡片写入 SullyOS 的本地数据库。
SullyOS 模式下可以点击“刷新”读取角色列表，在“发送给”里指定角色；保留“自动选择当前/最近角色”时，会沿用原来的自动定位逻辑。
SullyOS 会写入一条“网页分享”卡片到指定角色或当前/最近角色聊天。界面只显示卡片摘要，正文会放在这张卡片的上下文里；需要回复时，在 SullyOS 聊天页点击 ⚡ 触发 AI。
限制
只能读取用户当前页面里已经加载出来的文字。
图片、视频、canvas 里的文字暂不读取，后续可以加截图 OCR。
页面折叠内容、分页评论需要用户先展开或滚动加载。
浏览器内部页、扩展商店等受保护页面不能读取。
SullyOS 支持是“只改扩展”的兼容模式：它复用 SullyOS 已有 social_card 消息，不修改 SullyOS 源码；如果需要把网页正文也接入 SullyOS 记忆宫殿向量化，仍然需要在 SullyOS 项目里补一条正式的网页上下文链路。
