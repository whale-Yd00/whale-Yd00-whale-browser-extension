# Whale Browser Extension

读取当前网页正文，并把文字发送到 Whale 或 SullyOS。

## 功能

- 读取当前浏览器标签页中已经加载出来的文字
- 支持知乎、小红书等 Jina Reader 可能无法读取的登录态页面
- 可复制正文到剪贴板
- 可发送到 Whale 网页版
- 可发送到 SullyOS，并写入网页分享卡片
- SullyOS 模式支持选择发送给指定角色

## 安装

1. 打开 Edge / Chrome 扩展管理页：
   - Edge: `edge://extensions`
   - Chrome: `chrome://extensions`
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择本项目文件夹。

## 使用

1. 打开想读取的网页。
2. 点击扩展按钮。
3. 确认弹窗里读到了正文。
4. 选择目标应用：
   - `Whale-LLT`
   - `SullyOS`
5. 填写目标网页地址。
6. 点击发送。

SullyOS 模式下，可以点击“刷新”读取角色列表，然后在“发送给”里选择指定角色。

## 注意

- 扩展只会在用户点击时读取当前页面文字。
- 不读取 Cookie、token 或账号密码。
- 只能读取页面里已经加载出来的文字。
- 图片、视频、canvas 里的文字暂不支持。
- 浏览器内部页面和扩展商店等受保护页面不能读取。
